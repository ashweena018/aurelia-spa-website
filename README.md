# Aurelia Spa – Premium 3D Business Website

Aurelia Spa is a premium wellness and spa business website designed with a modern, elegant and calming visual style. The website uses a dark green background, warm gold accents and cream typography to create a luxurious atmosphere. It includes six pages: Home, About, Services, Gallery, Booking and Contact. The homepage features an animated 3D-style orb and floating elements to create an interactive visual experience. CSS animations, hover effects, responsive layouts and JavaScript interactions were used throughout the website. The Booking and Contact pages include interactive demo forms with confirmation messages. The website was tested for desktop and mobile responsiveness and deployed using GitHub Pages.
